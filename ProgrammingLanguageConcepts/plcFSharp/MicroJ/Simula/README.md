# Portable Simula Revisited

This folder contains two of the microJ examples translated to Simula
67 like code. The examples demonstrate some of the early Simula 67
object oriented design ideas.

Simula 67 supports subclasses, with a concept called prefixing. There
are differences to Java, e.g., you cannot access fields and procedures
in super class directly.

The examples:
-  helloworld.sim
-  ex01.sim (rewrite of ex01.java)
-  ex02.sim (rewrite of ex02.java)

Examples can run on the Portable Simula Compiler developed at the
University of Oslo, see

https://www.mn.uio.no/english/services/it/simula/compilers/portable-simula-revisited/
